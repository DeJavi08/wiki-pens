## 🤔 Apa itu React?



**React** adalah library JavaScript untuk membuat user interface (UI). Dibuat oleh Facebook (Meta) pada 2013, sekarang jadi salah satu library UI paling populer di dunia.



### Masalah yang React Selesaikan

</div>
