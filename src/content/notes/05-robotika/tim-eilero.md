# Tim EILERO (EEPIS Intelligent Legged Robot)

**EILERO (EEPIS Intelligent Legged Robot)** adalah tim robot SAR otonom PENS yang berkompetisi pada divisi **Kontes Robot SAR Indonesia (KRSRI)** (dahulu dikenal sebagai divisi Robot Pemadam Api Indonesia / KRPAI Berkaki). Robot ini dirancang untuk melakukan navigasi di arena simulasi bencana gempa dan kebakaran.

---

## 1. Arsitektur Rekayasa & Landasan Algoritma
- **Struktur Heksapoda & Tripod Gait**: Robot berkaki enam dengan 3 derajat kebebasan (3-DoF) pada setiap kaki (total 18 motor servo torsi tinggi); mengadopsi pola ayunan langkah *tripod gait* di mana tiga kaki selalu menumpu tanah sementara tiga kaki lainnya melangkah, menjamin kestabilan saat melewati tanjakan terjal, puing reruntuhan, kelereng, dan anak tangga.
- **Sistem Pemetaan Rute LiDAR & Navigasi SLAM**: Sensor 2D LiDAR berputar untuk mendeteksi dinding lorong labirin secara *real-time* dan menghitung jalur terpendek menuju ruang target.
- **Deteksi Sumber Api UVtron**: Tabung sensor ultraviolet Hamamatsu UVtron yang sangat sensitif terhadap spektrum radiasi nyala api tanpa terdistorsi cahaya matahari.
- **Mekanisme Penyelamatan Korban & Pemadam**: Gripper silikon lembut untuk mengangkat boneka korban bencana ke zona aman, serta pompa air tekanan tinggi terarah untuk memadamkan titik api.

---

## 2. Rekam Jejak Prestasi
- **Juara Konsisten KRI Wilayah dan Nasional**: Penguasa podium divisi robot pemadam api dan SAR berkaki medan terjal berkat kecepatan manuver lorong dan keberhasilan evakuasi korban 100%.
