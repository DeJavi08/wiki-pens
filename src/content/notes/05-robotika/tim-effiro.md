# Tim Robot Pemadam Api EFFIRO

**EFFIRO** adalah skuad robot pemadam api otonom beroda legendaris yang mengharumkan nama Indonesia dan Politeknik Elektronika Negeri Surabaya di kancah kejuaraan internasional bergengsi, seperti *Trinity College Fire Fighting Home Robot Contest* di Hartford, Connecticut, Amerika Serikat.

---

## 1. Arsitektur Rekayasa & Landasan Algoritma
- **Navigasi Lorong Presisi Berkecepatan Tinggi**: Mengandalkan sensor ultrasonik dan inframerah jarak dekat dengan kontroler PID penelusur dinding (*wall follower*) yang mampu bermanuver melintasi labirin rumah tinggal dalam hitungan detik.
- **Deteksi Titik Api & Pemadaman Efisien**: Pemindaian nyala api lilin menggunakan sensor UVtron, dilengkapi nosel semprotan gas CO2 atau kipas berkecepatan tinggi terfokus.
- **Transisi Menuju Misi SAR Modern**: Fondasi teknologi dan kode algoritma yang dikembangkan di EFFIRO kini diteruskan dan dikembangkan lebih lanjut pada skuad robot SAR berkaki [[Tim EILERO (EEPIS Intelligent Legged Robot)]].
