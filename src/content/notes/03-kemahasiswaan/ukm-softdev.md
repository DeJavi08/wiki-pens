# UKM Softdev (Software Development) PENS

![Logo Resmi UKM Softdev (Software Development)](https://javiahmad.it.student.pens.ac.id/mbx/images/UKM_Softdev_(Software_Development).jpg)

**UKM Softdev (Software Development)** adalah wadah inkubasi talenta rekayasa perangkat lunak di Politeknik Elektronika Negeri Surabaya. Unit ini membina kemampuan perancangan arsitektur piranti lunak berstandar industri, mulai dari antarmuka pengguna hingga sistem peladen terdistribusi berskala besar.

---

## 1. Bidang Keilmuan & Divisi Teknis
- **Full-Stack Web Development**: Pembangunan aplikasi web modern menggunakan ekosistem JavaScript/TypeScript (React, Next.js, Node.js), Python (FastAPI/Django), dan Go.
- **Komputasi Awan & DevOps**: Orkestrasi kontainer (Docker, Kubernetes), otomasi integrasi dan penggelaran berkelanjutan (CI/CD pipelines), serta pengelolaan infrastruktur awan (GCP, AWS).
- **Rekayasa API & Basis Data Terdistribusi**: Perancangan RESTful API dan GraphQL berkinerja tinggi, manajemen basis data relasional (PostgreSQL) serta NoSQL (MongoDB, Redis caching).
- **Perancangan Antarmuka & Interaksi (UI/UX)**: Riset pengalaman pengguna (*user research*), pembuatan purwarupa interaktif di Figma, dan penerapan sistem desain konsisten (*design system*).
- **Sistem Keamanan Siber Dasar**: Pengamanan otentikasi (OAuth2, JWT), enkripsi data, dan proteksi dari kerentanan umum OWASP Top 10.

## 3. Agenda Strategis & Kolaborasi Kampus
- **Inkubasi Proyek Sistem Informasi Kampus**: Membantu digitalisasi layanan organisasi kemahasiswaan dan sistem penunjang kegiatan kampus.
- **Delegasi Pagelaran Mahasiswa Nasional Bidang TIK (GEMASTIK)**: Mengirimkan kontingen PENS di divisi Pengembangan Aplikasi Perangkat Lunak (*Software Development*), Desain Pengalaman Pengguna (*UX Design*), dan Kota Cerdas (*Smart City*).
- **Tech Talks & Code Camps**: Lokakarya mingguan bedah teknologi dan arsitektur sistem bersama alumni yang berkarier di industri teknologi global.
